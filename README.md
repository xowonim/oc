# OC LIST by xowon

안녕하세요.. 반갑습니다 환영합니다
이 파일들을 이용해서 캐릭터들을 나열하고 서사 정리하는 사이트를 만들 수 있답니다

## 구조

```
index.html                       메인 페이지 (사이드바 + 갤러리 + 상세/생성/설정 모달)
css/style.css                     스타일
js/app.js                         데이터 로드, 정렬/그룹, 렌더링, 생성·수정 로직
data/worlds.json                  세계관(神世界/OC/YMKB/ETC) 정의, 정렬·분류 규칙, 항목(필드) 목록
data/characters/                  캐릭터 파일들 (파일 하나 = 캐릭터 한 명)
data/characters/_template.json    수동으로 만들 때 참고용 틀
assets/                           캐릭터 이미지
```

## 사이트에서 바로 캐릭터 추가/수정하기 (처음 한 번만 설정)

이 사이트는 깃허브에 직접 저장하기 위해 개인 토큰이 필요하다. 최초 1회만 설정하면 이후엔 사이트 안에서 버튼 클릭만으로 캐릭터를 만들고 고칠 수 있다.

1. 사이드바 아래 **⚙ 저장 설정**을 누른다.
2. 안내된 링크에서 새 토큰(fine-grained personal access token)을 발급한다.
   - Repository access: 이 저장소(`xowonim/oc`)만 선택
   - Permissions → **Contents: Read and write** 선택
3. 발급된 토큰을 복사해서 설정 창에 붙여넣고 저장한다. **이 기기의 브라우저에만 저장되고, 깃허브에는 올라가지 않는다.**

이후에는 갤러리의 점선 **"+ 캐릭터 생성"** 타일을 누르면 (깃허브 코드 화면이 아니라) **사이트 안에서** 바로 폼이 열린다.

## 캐릭터 생성/수정 폼

- **우측 상단 "+ 캐릭터 생성" 버튼**: 갤러리 화면 어디서든 우측 상단 고정 버튼을 누르면 폼이 열린다. 지금 보고 있는 세계관/하위 카테고리가 있으면 그 값이 기본으로 채워진다.
- **템플릿(세계관) 전환**: 이미지 영역 왼쪽 위에 겹쳐진 작은 드롭다운에서 神世界/OC/YMKB/ETC 중 고르면, 그 세계관의 항목 구성으로 폼이 즉시 바뀐다.
- **이미지 삽입(1) / 이미지 삽입(2)**: 이미지 영역 안에, 템플릿 선택 바로 아래에 나란히 있다. 서로 다른 이미지 두 장을 올릴 수 있다.
  - (1) → 메인 갤러리 카드에 뜨는 이미지
  - (2) → 캐릭터를 클릭했을 때 상세 화면에 뜨는 이미지
- **항목(필드) 관리**: 이미지 아래, **이름을 포함한 모든 기본 정보 항목**(이름/나이/소속 및 세계관마다 추가한 항목들)이 하나의 목록으로 나온다.
  - **이름**만 삭제할 수 없는 필수 항목(“필수 항목” 표시)이고, 나머지(나이/소속/역할/능력 등 세계관에 있는 모든 항목)는 전부 **추가·수정·삭제**가 가능하다.
  - 각 항목은 **텍스트 입력** 또는 **태그 입력**(여러 개를 칩 형태로 추가/삭제) 중 하나로 만들 수 있다.
  - 목록 맨 아래 **+ 항목 추가**로 새 항목(텍스트/태그 선택)을 만들면, 그 세계관의 모든 캐릭터 폼에 이후로 계속 나타난다. **항목 삭제**를 누르면 그 항목이 세계관에서 빠진다(기존 캐릭터에 저장된 값 자체는 남아있지만 화면엔 더 이상 안 보인다).
  - 部(1부~5부)·세부 분류(오토리 일행 등)·학년/학급은 사이드바 이동·정렬 기준으로도 쓰이기 때문에 이 목록과 별개로, 항목 목록 바로 위에 드롭다운/숫자 입력으로 따로 있다.
- **소개 / 성격 / 작중행적 / 여담**: 항목 목록 아래 고정으로 있는 네 개의 서술형 칸. **작중행적은 神世界 캐릭터에만** 나온다.

토큰 설정을 안 했거나 저장이 실패하면, 폼 아래 안내에 따라 깃허브에서 수동으로 처리할 수 있다.

## 수동으로 캐릭터 파일 만들기 (토큰 없이)

1. `data/characters` 폴더의 `_template.json`을 열어 내용을 복사한다.
2. **Add file → Create new file**에서 파일 이름을 `data/characters/캐릭터영문이름.json`으로 입력.
3. 내용을 붙여넣고 값을 채운 뒤 Commit. (파일 이름이 `_`로 시작하면 목록에서 제외되니 새 파일명에는 밑줄을 넣지 않는다.)

## 캐릭터 파일의 필드

```json
{
  "id": "character-id",
  "world": "sinsekai",
  "part": "1부",
  "subcategory": "오토리 일행",
  "name": "캐릭터 이름",
  "grade": null,
  "class": null,
  "image": null,
  "profileImage": null,
  "fields": { "age": "0", "affiliation": "소속", "role": "-", "power": [] },
  "bio": "소개",
  "personality": "성격",
  "history": "작중행적",
  "trivia": "여담"
}
```

- `world`: `sinsekai`(神世界) / `oc`(OC) / `ymkb`(YMKB) / `etc`(ETC) 중 하나.
- `name`: 최상위(`fields` 밖)에 있는 유일한 필수 항목. 카드/상세 제목, 정렬에 쓰인다.
- `part`: **神世界 캐릭터만** 적는다. `1부`~`5부` 중 하나 — 사이드바의 하위 필터로 쓰인다.
- `subcategory`: **神世界·OC 캐릭터만** 적는다.
  - 神世界: 오토리 일행 / 음양오행의 신 / 이원향 / 글리샬라볼라스 / 바드르 제단 / 예레미야 / 예르모 행성 — 갤러리에서 이 이름으로 구역이 나뉜다.
  - OC: 요조라 / 미조레 / 시노노메 — 사이드바 하위 필터로 쓰인다.
- `grade`, `class`: **OC·YMKB 캐릭터만** 적는다 (학년/학급 순 정렬에 쓰인다).
- `image`: 갤러리 카드에 쓰는 이미지. 없으면 `null`. 있으면 `"assets/파일명.png"`.
- `profileImage`: 상세 화면에 쓰는 이미지. 없으면 갤러리 이미지가 대신 쓰인다.
- `fields`: **이름을 제외한 모든 기본/추가 항목**(나이, 소속, 그리고 세계관마다 다른 역할/능력 등)이 여기 들어간다. `data/worlds.json`의 해당 세계관 `fields` 키와 이름이 같아야 값이 화면에 뜬다. 태그 항목은 배열(`[]`), 텍스트 항목은 문자열.
- `bio`/`personality`/`history`/`trivia`: 소개/성격/작중행적/여담. `history`는 神世界 캐릭터만 의미가 있다.
- ETC 캐릭터는 `part`, `subcategory`, `grade`, `class`가 필요 없다 — 이름만 맞으면 정해진 순서(아래 참고)대로 자동 정렬된다.

## 정렬·분류 규칙 (자동)

- **All**: 이름 가나다순.
- **神世界**: 사이드바에서 1부~5부로 필터링. 갤러리는 항상 오토리 일행→음양오행의 신→이원향→글리샬라볼라스→바드르 제단→예레미야→예르모 행성 순서로 구역이 나뉘어 표시된다.
- **OC**: 사이드바에서 요조라/미조레/시노노메로 필터링. 그 안에서 학년 오름차순 → 학급 오름차순 → 이름순.
- **YMKB**: 학년 오름차순 → 학급 오름차순 → 이름순.
- **ETC**: `data/worlds.json`의 `fixedOrderList`에 적힌 이름 순서대로.

모든 카테고리의 선택(활성) 색상은 통일되어 있다 (All을 눌렀을 때와 같은 색).

## 이미지만 따로 올릴 때

사이트 폼으로 올리는 게 가장 쉽지만, 직접 올리고 싶다면 `assets` 폴더에서 **Add file → Upload files**로 올린 뒤 캐릭터 json의 `image`(또는 `profileImage`) 값을 `"assets/올린파일명.png"`로 수정하면 된다.

## 세계관 자체를 바꾸는 법

`data/worlds.json`을 연다. (사이트 안 항목 관리 기능으로 `fields`는 자동으로 바뀌지만, 그 외 구조를 바꾸려면 직접 연다.)

- `id`, `name`, `shortName`, `color`: 기본 정보.
- `parts`: 있으면 사이드바 하위 필터가 된다 (神世界).
- `subcategories`: `parts`가 없으면 사이드바 하위 필터 + 정렬 기준이 된다 (OC). `groupInGallery: true`와 함께 있으면 사이드바 대신 갤러리 구역 제목으로 쓰인다 (神世界).
- `useGradeClass`: `true`면 학년/학급 정렬을 적용.
- `fixedOrderList`: 있으면 이름 기준 고정 순서 정렬 (ETC).
- `hasHistory`: `true`면 상세/폼에 "작중행적" 칸이 나온다 (현재 神世界만).
- `fields`: 상세 모달·생성 폼에 보여줄 기본/추가 항목 전부. `key: "name"`이면서 `core: true`인 첫 항목은 삭제 불가(이름)이고, 나머지는 사이트 안 "항목 관리"에서 자유롭게 추가·수정·삭제된다. `type`은 `"text"` 또는 `"tags"`.

## 깃허브 Pages 켜기

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정하고 저장한다.

## 전체를 한 번에 올리는 법 (파일 하나씩 올리기 힘들 때)

1. 받은 zip 파일의 압축을 아이패드에서 푼다 (Files 앱에서 압축 파일을 탭하면 자동으로 풀린다). `oc-site`라는 폴더가 생긴다.
2. 저장소의 기존 파일을 전부 지운다 — 이미 열려 있는 파일이 있으면 지우지 말고, 저장소 메인 페이지에서 파일들을 하나씩 선택 후 삭제하거나, 새로 시작하는 경우가 아니면 이 단계는 생략해도 된다 (같은 이름의 파일은 업로드 시 자동으로 덮어써진다).
3. `https://github.com/xowonim/oc/upload/main/` 페이지를 연다.
4. Files 앱을 스플릿뷰(또는 슬라이드오버)로 옆에 띄운 뒤, **압축을 푼 `oc-site` 폴더를 통째로** 드래그해서 브라우저의 업로드 영역에 놓는다. (폴더 안의 파일 하나씩이 아니라 **폴더 자체**를 드래그해야 `css/`, `js/`, `data/` 같은 하위 폴더 구조가 그대로 유지된다.)
5. 업로드된 파일 목록에 `index.html`, `css/style.css`, `js/app.js`, `data/worlds.json`, `data/characters/_template.json`, `data/characters.fallback.json`, `README.md`가 모두 보이는지 확인하고 **Commit changes**를 누른다.

드래그가 잘 안 되면, 대안으로 깃허브 저장소 메인 화면의 **Add file → Upload files**에서도 폴더째로 드래그하면 동일하게 동작한다.
